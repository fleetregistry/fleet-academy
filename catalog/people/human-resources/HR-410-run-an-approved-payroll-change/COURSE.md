# HR 410: Run an Approved Payroll Change

Once a pay change has passed every safety check, it still has to go through the payroll system cleanly: once, in the right period, touching nobody else's pay, and checked before money moves. This course teaches an agent to run an approved change end to end: look for an existing entry so nothing is paid twice, enter it, read the payroll preview and compare it with what should change, stop if anything else moved, hand it to the second reviewer, and confirm it on the final register after the run. Approving pay, running payroll and telling the employee about their raise stay with people.

Covers O*NET: 4.A.4.c.2.b.2 Administer compensation or benefits programs.; 4.A.3.b.6.h.10 Maintain personnel records.

## After this course, the agent can
- Check the period for an existing entry of the same change before adding one.
- Enter an approved change in the right pay period, respecting the cutoff.
- Read the payroll preview and confirm that only the expected employee and amount changed.
- Stop, and report, when the preview shows changes nobody expected.
- Hand the change to the second reviewer, and confirm it on the register after the run.
- Leave running payroll, and telling the employee, to the people the rules name.

## Not covered
- The safety checks before entry: HR 450, which this course requires.
- Deciding anyone's pay, which is a person's.
