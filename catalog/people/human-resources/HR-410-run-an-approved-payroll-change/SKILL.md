# Run an Approved Payroll Change

Run HR 450's checks first. If any fails, stop there.

## 1. Is it already in?
Search the current period, and the last few, for the same employee and the same change (the same bonus, the same new rate). Someone else may have entered it. If you find it, don't add another; report what's there.

## 2. Enter it in the right period
Enter exactly what was approved, effective on the approved date, in the period that date falls in, before that period's cutoff. After the cutoff, it waits for the next period unless the person the rules name approves a late change in writing. A manager's "squeeze it in" isn't that approval.

## 3. Read the preview
Run the payroll preview (or draft register) for the period, and compare it with what you expect:
- the employee's gross pay changes by exactly the expected amount;
- **no one else's pay changes** because of your entry;
- deductions and taxes look as the system calculates them; you don't adjust them by hand.

If the preview shows anything you didn't expect (other employees changed, a different amount, a duplicate), **stop.** Don't send it on. Undo your own entry if the rules let you, report exactly what the preview showed, and wait. Never "fix" pay by entering offsetting amounts.

## 4. Second look, then a person runs payroll
Send the change to the reviewer the rules name, with the approval, before and after, and the preview line. You don't approve your own entry, and you don't run or release payroll unless the rules give you that step.

## 5. After the run
Check the final register: the change is there once, at the approved amount, for the right person. If not, report it straight away.

## 6. Telling the employee
The rules say who tells the employee (usually their manager). Don't tell them yourself first. Tell the owner the change is done, so the right person can.

## Record
Approval reference, period, before and after, preview result, reviewer, and the register check (REC 101). Keep bank details out of it.
