# Carry Out a Deletion Request

All of PRV 350 must already have passed: verified, approved, scoped by ID, holds and retention checked, preview confirmed. This course is doing it, everywhere, and proving it.

## 1. Make the system list
Start from the owner's process, which should list every place personal data lives. Typically:
- the main database or CRM,
- the email or marketing tool,
- the support desk,
- **exports and copies:** spreadsheets in shared drives, reports, downloaded lists,
- **vendors** that hold the data for the company (they get a deletion request, usually through a ticket or form the process names).

Write one line per system and work down it. If you find the person's data somewhere the process doesn't list, don't skip it and don't improvise: tell the privacy contact.

## 2. Keep the suppression entry
Most processes keep a minimal "do not contact" entry (often just the email, or a hashed form of it) so the person isn't added back and emailed again by the next import. **Deleting someone must not remove them from the suppression list.** If someone asks you to remove it "so they're completely gone," explain that it's what stops the company contacting them again, and follow the process.

## 3. Delete, then check
For each system:
- delete exactly the approved records,
- **search again** by the same identifiers and note the result ("CRM: 0 results for account 5120"),
- for a vendor, record the ticket or reference number and the date they confirm.

## 4. Report what's true
- If every system checks out: say so, with each system's result.
- If anything failed (a locked record, an error, a vendor that hasn't confirmed), say exactly which, why, and what's needed. **Never report "done" or "all deleted" while anything is left.** Partial is partial.

## 5. The confirmation to the person
- Draft it from the process's template. It must be accurate: if records were kept under the retention rule, it says so in the words the process gives; if a system is still pending, it doesn't say "everything has been deleted."
- Send the draft to the privacy contact for approval. Send it to the person only after approval, through the verified contact.

## 6. Record
Record (REC 101) per system: what was deleted, the check result, vendor references, and when. Use the request ID, not the person's details.
