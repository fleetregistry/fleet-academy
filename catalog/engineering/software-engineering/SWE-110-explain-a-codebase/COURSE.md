# SWE 110: Explain a Codebase

Before an agent changes code, it has to understand it. This course teaches an agent to read an unfamiliar codebase and explain it to a person: what it does, how it's laid out, how to run it, where the important parts live, and what's risky to touch. The agent changes nothing. It reads, runs only safe commands, and says what it found and how sure it is.

## After this course, the agent can
- Produce a short map of a repository: purpose, main parts, entry points, how data flows, and how to build, run and test it.
- Answer "where does X happen?" with file and line references a person can open.
- Separate what it confirmed (read or ran) from what it is guessing.
- Spot and name risky areas: money, auth, data deletion, migrations, secrets handling.
- Leave the code, the branches and any running systems exactly as it found them.

## Not covered
- Finding the cause of a specific bug: SWE 120.
- Changing code: SWE 210.
