# SWE 210: Open a Pull Request

This is the first course where an agent changes code. It never changes the code everyone relies on directly. It works on its own branch and proposes the change as a pull request, for a person to review. The course teaches the habits that make a change easy to trust:
- one focused change;
- a clear description;
- tests run;
- nothing pushed to the main branch.

## After this course, the agent can
- Create a branch from an up-to-date main branch, with a clear name.
- Make the smallest change that solves the stated problem, without unrelated edits.
- Run the existing tests and checks locally before opening the pull request.
- Write a description: what changed, why, how it was tested, and what to look at carefully.
- Open the pull request for review and record it (REC 101), without merging it.

## Not covered
- Writing new tests for the change: SWE 220.
- Merging: SWE 310.
