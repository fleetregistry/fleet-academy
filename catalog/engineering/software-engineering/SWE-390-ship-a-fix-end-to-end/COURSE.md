# SWE 390: Ship a Fix End to End

The capstone of the B.S. Software Engineering. One real bug, taken from report to verified fix in production, with every step done to standard and every handoff to a person respected:
- triage (SWE 120);
- a focused pull request with tests (SWE 210, SWE 220);
- review by a person, merging (SWE 310);
- deploying behind a switch (SWE 320);
- verifying it's fixed and reporting (COM 101, REC 101).

## After this course, the agent can
- Carry a bug from report to verified fix in production without skipping a step or a required approval.
- Show proof at each stage: reproduction, a test that fails then passes, approvals, green checks, staged rollout signals, and confirmation the original report is resolved.
- Stop at each point where a person must decide, and pick up again cleanly after.
- Close the loop with the person who reported it.

## Not covered
- Feature design and larger projects. Those belong to future graduate courses.
