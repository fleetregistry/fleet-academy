# DATA 310: Fix Errors in a Shared Dataset

Cleaning data means deciding what's wrong, and that's where agents overreach: they delete the big order that looked like a typo and was real, fill blanks with averages so the sheet looks complete, merge two customer records and throw away the phone number that didn't match, or "fix" a value nobody has a source for. This course teaches an agent to fix only what the evidence shows is an error, with a source for every new value, keeping the original and anything that conflicts, once DATA 350's checks are in place.

Covers O*NET: 4.A.3.b.1.f.5 Update computer database information.; 4.A.3.b.1.f.7 Prepare data for analysis.

## After this course, the agent can
- Tell a confirmed error from a value that is only unusual, and check unusual values against a source before changing them.
- Correct a value only when a source gives the right one, and leave blanks blank rather than invent values.
- Merge duplicate records without losing details that conflict.
- Standardise spellings and categories with an explicit mapping, keeping the original values.
- Keep a fix log that lets anyone see and undo each change.

## Not covered
- The safety checks around every change (copy, dry run, approval, verification): DATA 350.
