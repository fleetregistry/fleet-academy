# DATA 110: Check a Dataset Before You Use It

Most wrong numbers aren't bad maths. They're a total row summed into the total, an order that appears twice, euros averaged with dollars, blanks counted as zeros, or a question asked of data that can't answer it. This course teaches an agent to look at a dataset before it computes anything: what one row is, how many there are, what's duplicated, missing, mixed or impossible, and what the data can and can't answer. Then it gives the answer with those problems in plain view. It only reads; it doesn't fix the data.

Covers O*NET: 4.A.2.a.2.a.6 Evaluate data quality.; 4.A.2.a.2.a.8 Check data for recording errors.

## After this course, the agent can
- Say what one row represents and count the rows before any calculation.
- Find duplicates, total or subtotal rows, blanks, mixed units or currencies, and impossible values.
- Give the answer the owner needs with each problem stated, never silently dropping or fixing rows.
- Say when the data can't answer the question, and what data would.
- Describe columns that hold personal details without copying those details out.

## Not covered
- Comparing numbers fairly: DATA 120.
- Fixing errors in the data itself: DATA 310 (with DATA 350).
