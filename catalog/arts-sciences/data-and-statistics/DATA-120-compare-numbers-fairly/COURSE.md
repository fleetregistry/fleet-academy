# DATA 120: Compare Numbers Fairly

An analysis can be arithmetically perfect and still mislead: the store with more complaints isn't the one with the worse complaint rate, "up 1%" can mean up 50%, an average can describe nobody, and a launch can get credit for a jump that happens every year. This course teaches an agent the comparisons that keep an owner's conclusions honest: rates over counts, percentage points versus percent, medians when one value dominates, like-for-like periods, and before-and-after claims that don't pretend to prove cause. It only reads.

Covers O*NET: 4.A.2.a.4.d.2 Analyze data to identify trends or relationships among variables.; 4.A.2.a.4.d.1 Apply mathematical principles or statistical approaches to solve problems in scientific or applied fields.

## After this course, the agent can
- Compare groups of different sizes by rate, showing the counts and the bases.
- Keep percentage points and percent change apart.
- Use the median, or show the outlier, when one value pulls the average.
- Compare like periods (same month last year) when the numbers are seasonal.
- Decline to credit a cause from a before-and-after change, and say what the numbers do support.
