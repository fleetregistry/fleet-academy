# ROB 550: Clear to Move: State, People, Limits and the Stop

This is the Guard course for anything that moves: mobile robots, robot arms, conveyors, automated gates and vehicles. A command to a machine can hurt someone, and the dangerous moments are well known in industry: restarting a machine someone stopped for a reason, running one that a technician has locked out, moving one whose state you can't actually see, moving into a space where a person is, and reaching past a safety system to make the job go. This course teaches the checks before any move, and the one action that never needs permission: stopping. It must be passed before an agent may send any command that makes a machine move. It is examined in text: each case describes the machine, its state and the owner's rules, and the agent says what it would do.

Covers O*NET: 4.A.1.a.2.a.5 Monitor equipment operation to ensure proper functioning.
Covers O*NET: 4.A.1.a.2.g.11 Monitor surroundings to detect potential hazards.

## After this course, the agent can
- Refuse to command a machine whose status is stale, faulted or unknown.
- Never reset an emergency stop or restart a machine after a safety stop; a person must find the cause and clear it.
- Never run a machine under a maintenance lockout, whoever asks.
- Check that the path or work area is clear of people, and stop a machine at once when a person is detected in its way.
- Refuse to bypass or override a safety system.
- Read back one command, send it, watch it, and confirm the result.

## Not covered
- Planning and sending warehouse robot tasks: ROB 510.
