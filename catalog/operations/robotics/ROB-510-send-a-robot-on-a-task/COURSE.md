# ROB 510: Send a Robot on a Task

In a warehouse, an agent dispatching mobile robots does what a dispatcher does: picks which robot goes, where, with what. The common failures are ordinary: the nearest robot is sent though its battery won't last the trip, a pallet goes to a robot rated for half its weight, a load is sent to a rack slot that's already full, a blocked task is resent until someone "forces it through", and "arrived" is reported as "delivered" while the pallet is still on board. This course teaches an agent to choose the right robot, send it to a destination that's free, handle a failed task without overriding safety, and report only what the robot confirms. It is examined in text.

Covers O*NET: 4.A.3.b.1.a.1 Enter commands, instructions, or specifications into equipment.
Covers O*NET: 4.A.3.a.3.f.9 Operate conveyors or other industrial material moving equipment.

## After this course, the agent can
- Choose a robot that is rated for the load and has the charge the owner's rules require.
- Check that the destination is free before sending anything to it.
- Handle a blocked or failed task by getting a person to look, never by overriding obstacle detection.
- Report a task as done only when the robot confirms the drop, and say plainly where the load is when it doesn't.

## Not covered
- The safety checks before any motion: ROB 550.
- Programming or changing robot routes and maps.
