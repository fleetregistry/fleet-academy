# Reconcile a Count

Every change you make here goes through the checks in INV 350 (cutoff, thresholds, read-back, no deletes). This course is about deciding **what** each line needs.

## 1. Lay out every line
For each line: item, location, system quantity at the count's cutoff, counted quantity, unit, difference in units and in money. Do the cutoff check (INV 350) first, so you're comparing like with like.

## 2. Explain before you adjust
Go through the likely causes, in this order, before calling anything a real gain or loss:
1. **Units.** Did the counter count units where the system holds cases (36 counted, system says 3 cases of 12)? Then there's no difference.
2. **Misplacement.** Look for the same item short in one location and over in another, especially neighbouring bins. Equal and opposite differences are almost always stock in the wrong place. Fix it with a **move (transfer)** between locations, not two adjustments. The company's total doesn't change.
3. **Timing.** Receipts not yet put away, picks not yet confirmed, goods on the dock.
4. **Paperwork.** A receipt posted to the wrong item, a pick confirmed for the wrong quantity.

## 3. Recount what's in doubt
If a difference isn't explained and is over the owner's recount threshold, ask for a recount by a different person.
- If the recount agrees with the system, the first count was wrong. **No adjustment.**
- If the recount agrees with the first count, the difference is real.
- If all three disagree, count again, or ask a person.

## 4. Adjust what's left, within limits
Only now post adjustments for real, explained-as-far-as-possible differences that are within the owner's limits, one per item, each with a reason.

## 5. Escalate
Send to the person the owner names, before any write-off:
- Differences over the approval limit.
- Any shortage of serialized, controlled or high-value items (laptops, tools, drugs, precious metals). These may be theft or loss that someone has to look into, not paperwork. Give the facts from the record (item, serial numbers, quantity and value missing, what each count found), don't adjust, and don't speculate about who took them. If someone asked you to write them off, tell them it has gone to that person instead.

## 6. Report
Lead with the result: how many lines matched, what you moved, what you adjusted (units and value), what's waiting for a recount or a decision. Then each line that changed, with its reason.
