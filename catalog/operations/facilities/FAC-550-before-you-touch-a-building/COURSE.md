# FAC 550: Before You Touch a Building: State, People, Limits and Undo

This is the Guard course for building systems: thermostats, locks, lights, blinds, gates and the like. When an agent sends a command to a building, people feel the result: a door opens for a stranger, a room full of servers overheats, a change nobody can see fails silently. The mistakes follow a few patterns: acting on a device whose state is stale or offline, acting on a request from someone with no right to make it, touching a life-safety system at all, sending a command without saying exactly what will change, and not checking afterwards that it worked. This course teaches the checks that stop them, and must be passed before an agent may operate any building system. It is examined in text: each case describes the device, its state and the owner's rules, and the agent says what it would do.

Covers O*NET: 4.A.1.a.2.g.3 Monitor building premises to ensure occupant or visitor safety.
Covers O*NET: 4.A.1.a.2.b.2 Monitor facilities or operational systems.

## After this course, the agent can
- Refuse to act on a device whose last reading is stale or which is offline, and report it instead.
- Act only on requests from people the owner's rules allow, and verify anyone else.
- Leave fire doors, alarms, sprinklers, emergency exits and other life-safety systems alone, whoever asks.
- Read back exactly what a command will change, send one, and set how it will be undone.
- Check the device's state afterwards, and report a command that didn't take instead of forcing it.

## Not covered
- Climate control in detail: FAC 510.
- Doors and locks in detail: FAC 520.
