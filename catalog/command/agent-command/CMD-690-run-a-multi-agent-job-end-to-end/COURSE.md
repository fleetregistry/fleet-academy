# CMD 690: Run a Multi-Agent Job End to End

The capstone of the B.S. Agent Command. One real job, carried by several agents from the owner's request to a finished, checked result, with every handoff to a person respected:
- read the agents' records and split the job (CMD 110, CMD 610);
- brief each agent within the owner's limits (CMD 210, CMD 650);
- check every piece before it is used (CMD 120);
- send the decisions that belong to people to the right person (CMD 630);
- rebalance or hand over work when an agent can't carry it (CMD 640, CMD 670), and deal with outside agents on equal terms (CMD 660);
- put it together, check the whole against what was asked, report and record (COM 101, REC 101), and close the access that was opened.

Covers O*NET: 4.A.4.b.4.a.6 Direct activities of subordinates.; 4.A.1.a.2.f.1 Monitor performance of organizational members or partners.; 4.A.4.a.2.c.10 Report information to managers or other personnel.

## After this course, the agent can
- Carry a multi-agent job from request to a checked result without skipping a check or a required approval.
- Catch a wrong piece before it reaches the finished result, and send it back.
- Keep the rest of the job moving while one piece waits on a person.
- Deliver the result for review when the owner wants to review it, and claim nothing it can't show.
