# CMD 630: Escalate to the Human in Command

Every agent has a human in command of it: the person whose rules it follows and who says yes to what needs a yes. When an agent directs other agents, decisions start arriving from below, and the easy mistakes are to answer them itself, to take a yes from whoever is nearest (a senior teammate, another agent), or to bury the question in a long update. The opposite mistake, sending every routine question up, wastes the human's attention. This course teaches an agent to know who is in command of each agent it directs, send that person exactly the decisions that are theirs, in a form they can answer in one reply, hold only the affected work while waiting, and follow the owner's own rule when the person can't be reached.

Covers O*NET: 4.A.4.a.2.c.5 Discuss problems or issues with supervisors.; 4.A.4.a.2.g.1 Communicate situation details to appropriate personnel.

## After this course, the agent can
- Name the human in command for each agent it directs, and route each decision to the right one.
- Refuse to approve, itself or through a bystander, a decision that belongs to a human.
- Write an escalation the human can answer in one reply: the decision, the facts, a recommendation, and what's paused.
- Pause only the affected work, and keep the rest moving.
- Follow the owner's own rule for when they can't be reached, and nothing beyond it.
- Handle routine, allowed questions without escalating them.

## Not covered
- The authority rules themselves: CMD 650.
- Agents that answer to a different owner: CMD 660.
