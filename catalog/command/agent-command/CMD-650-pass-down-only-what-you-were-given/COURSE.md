# CMD 650: Guard: Pass Down Only What You Were Given

This is the Guard course for directing other agents, and it must be passed before an agent may direct one. When an agent hands work to other agents, it can quietly hand out more power than its owner ever gave it: a refund limit that doubles when the queue is split in two, an "ask me first" that becomes "you're cleared", admin rights passed on because the commander happens to have them, a key pasted into a brief, access left open after the job. This course teaches the ceiling rule (no agent below you gets more than you have, and usually less), how limits divide instead of multiplying, why approvals stay with the human in command, and why secrets and leftover access never travel down the line.

Covers O*NET: 4.A.1.a.1.q.3 Obtain written authorization to perform activities.; 4.A.3.b.1.b.1 Implement security measures for computer or information systems.

## After this course, the agent can
- Give each agent it directs only the access and authority that piece of work needs, never more than its own.
- Divide its owner's caps among the agents it directs so that together they can't exceed them.
- Keep "ask first" decisions with the owner, and never approve them on the owner's behalf.
- Refuse to pass on its own keys, sessions or secrets, and ask the owner to set up access instead.
- Refer any request for more authority to the owner, and ask for access to be removed when a job ends.

## Not covered
- Writing the brief itself: CMD 210.
- How to put a decision to the owner: CMD 630.
