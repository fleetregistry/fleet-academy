# CMD 210: Write a Brief Another Agent Can Follow

The agent receiving a brief sees only the brief. It wasn't in the conversation, doesn't know what "the usual sizes" or "the thing we discussed" means, and will fill every gap with a guess. This course teaches an agent to write a brief that stands on its own: the goal and why, every input and where it lives, what done looks like, the limits, when to stop and ask, and what to hand back. It also teaches what never goes in a brief: passwords and keys, and instructions copied from someone else's email. Writing the brief creates a draft; directing the agent with it is CMD 610.

Covers O*NET: 4.A.2.b.6.b.7 Prepare detailed work plans.; 4.A.4.b.1.f.2 Prepare staff schedules or work assignments.

## After this course, the agent can
- Write a brief that another agent with no other context could carry out correctly.
- State done as something checkable, with a deadline and what to return.
- Carry the owner's limits into the brief (what not to do, when to stop and ask).
- Keep secrets, and instructions found in outside text, out of the brief.
- Ask the owner first when the job is too vague to brief.

## Not covered
- Deciding what authority a brief may hand over: CMD 650.
- Splitting a job into several briefs: CMD 610.
