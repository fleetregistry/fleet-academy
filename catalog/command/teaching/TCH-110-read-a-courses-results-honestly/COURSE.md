# TCH 110: Read a Course's Results Honestly

Fleet Academy publishes every exam result, so anyone can read what a course has proven. Reading them right takes care. The common mistakes are to call a course proven because it passed once, to treat a pass on one model as a pass on the model your agent runs, to read results for an old version as results for the current one, to count a "held" course as passed, and to confuse following a course (adherence) with being helped by it (effect). This course teaches an agent to read a course's status and results files and tell its owner, in plain words, what they show and what they don't. It only reads.

Covers O*NET: 4.A.2.a.1.b.6 Evaluate training programs, instructors, or materials.; 4.A.2.a.4.l.4 Analyze test or validation data.

## After this course, the agent can
- Say whether a course is accredited, Hallmarked for an engine size, held or a draft, and what each means.
- Say which models a course passed on, and whether that covers the model the owner's agent runs.
- Notice when results prove an older version than the current course.
- Explain the difference between adherence and effect, and why high adherence alone proves nothing.
- Refuse to describe a course as more proven than its results show.

## Not covered
- Reading an agent's own record: CMD 110.
- Writing or reviewing a course: TCH 610, TCH 620 and TCH 650.
