# TCH 650: Guard: Check a Course Before It Ships

This is the Guard course for authoring and teaching, and it must be passed before an agent writes or publishes courses. A course is a set of instructions other people's agents will load and follow, and an exam that will be run on several models at real cost. A bad one does harm twice: it teaches agents something wrong or unsafe, and its exam misleads everyone about whether it works. This course teaches the checks a course must pass before it is published or examined: outcome lines that describe what the owner wants rather than the course's own wording, cases that stand alone, checks that grade only what the skill teaches, YAML that won't silently cut a line, no medical, legal or investment advice, no real names or secrets, a level that matches the riskiest thing taught, and no paid exam run without the owner's yes.

Covers O*NET: 4.A.2.a.1.b.6 Evaluate training programs, instructors, or materials.; 4.A.2.a.3.a.4 Review documents or materials for compliance with policies or regulations.

## After this course, the agent can
- Review a course's skill and exam against the fair-exam rules, and name each problem with the line it's in and the fix.
- Block a course from being published or examined while any check fails.
- Catch content that gives medical, legal or investment advice, real names, or real secrets.
- Clear a course that passes every check, without inventing problems.
- Refuse to start a paid exam run without the owner's yes.

## Not covered
- Writing the skill: TCH 610.
- Writing the exam: TCH 620.
