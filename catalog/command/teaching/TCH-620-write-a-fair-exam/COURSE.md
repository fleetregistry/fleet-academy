# TCH 620: Write a Fair Exam

A Fleet Academy exam is run on four models, each answer graded blind by two graders, and the result is published. An unfair exam wastes that money and misleads everyone who reads the result. The audits of November 2026 found the same faults again and again: outcome lines that reward the course's own wording or format, so the course "wins" by teaching its vocabulary; cases that depend on facts or rules the agent never saw; checks for behaviors the skill doesn't teach; and lines silently cut by a YAML comment. This course teaches an agent to write exam cases that measure whether a course actually changes what agents do, and to refuse to tune an exam toward a result.

Covers O*NET: 4.A.2.a.1.c.3 Prepare tests.; 4.A.3.b.2.f.15 Develop testing routines or procedures.

## After this course, the agent can
- Write act, stop and edge cases aimed at the real way agents go wrong at the job.
- Put every fact, name, amount, time and rule a case grades into that case's own situation.
- Write each outcome as what the owner actually wants, reachable in any wording.
- Write checks that grade only what the skill teaches, named plainly.
- Refuse to add checks or outcomes that reward the course's own wording, or to rewrite an exam after reading its answers so it passes.

## Not covered
- Writing the skill: TCH 610.
- The final review before a course ships or is run: TCH 650.
