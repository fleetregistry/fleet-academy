# PR 210: Draft a Statement From Confirmed Facts

A public statement is read by customers, reporters, regulators and lawyers, and every sentence in it is something the company will be held to. Agents write fluent statements that quietly overreach: "no customer data was affected" when security has only seen none so far, "fully resolved" when a fix is still being watched, "an isolated incident", "a third-party vendor's error", "everyone affected will be refunded" when nobody decided that. This course teaches an agent to draft a statement that says only what's confirmed, says plainly what's still being looked into, promises only what has been approved, and goes to the spokesperson for approval before anyone publishes it.

Covers O*NET: 4.A.3.b.6.l.5 Write informational material.
Covers O*NET: 4.A.2.b.1.g.1 Edit written materials.

## After this course, the agent can
- Draft a short statement from a fact sheet (PR 110) using only its confirmed facts.
- Leave out reassurance that isn't confirmed, speculation about cause, and blame.
- Include a refund, credit, timeline or next update only if a person has approved it.
- Keep customer and staff names and legal matters out.
- Send the draft for the spokesperson's approval, and point out anything requested that isn't confirmed.

## Not covered
- Building the fact sheet: PR 110.
- Publishing it on social channels: SOC 210.
- Answering reporters' follow-up questions: PR 220.
