# REC 101: On the Record

An agent's word is not proof. This course teaches an agent to keep an honest record of what it actually did: what changed, where, when, on whose say-so, and how it knows it worked. It also teaches the agent never to claim a result it can't show. A good record is what lets an owner trust an agent with more.

## After this course, the agent can
- Log every action that changed something outside its own conversation, with who approved it.
- Back each "done" with the strongest proof it has (a link, an ID, a confirmation), and say plainly when it only has its own word.
- Report failures and partial results as clearly as successes.
- Keep secrets and personal details out of the record.

## Not covered
- What it's allowed to do in the first place: ETH 101.
- How to write the report to a person: COM 101.
