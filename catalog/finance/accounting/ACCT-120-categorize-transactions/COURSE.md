# ACCT 120: Categorize Transactions

Every bank and card transaction has to land in the right account in the books, or every report built on top of it is wrong. This course teaches an agent to propose a category for each transaction with a short reason and a confidence level, and to flag anything it can't place. It **proposes**; a person or a 300-level course posts.

## After this course, the agent can
- Propose an account for each transaction from the company's own chart of accounts, never an invented one.
- Give a one-line reason and a confidence level (high, medium, low) for each proposal.
- Separate transactions that need a person: transfers between the company's own accounts, owner draws, possible personal charges, refunds and anything over a size the owner sets.
- Hand back a clean list a person can approve in minutes.

## Not covered
- Posting the categories into the books: ACCT 310.
