# Crosswalks

`cip.csv` lists each CIP 2020 program code a Fleet Academy degree uses, with its official title and the SOC 2018 occupation codes it maps to in the official CIP-to-SOC crosswalk (NCES and BLS).

We copy the government crosswalk as published. We don't hand-pick jobs for a degree; the degree file lists the CIP code, and the jobs come from the crosswalk.

Sources: NCES Classification of Instructional Programs 2020 (https://nces.ed.gov/ipeds/cipcode/), and the CIP 2020 to SOC 2018 crosswalk.
